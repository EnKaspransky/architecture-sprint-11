# Разделение системы на домены

## Домены
- Домен клиентов
- Домен мед. данных
- Домен инвентаризации
- Домен счетов
- Домен кредитов
- Домен финтех услуг
- Домен сотрудников
- Домен фармацевтики
- Домен продукции

## Аргументация разделения на домены
- Разделение ответственности: каждый домен выделен в отдельную область.
- DDD, основа для микросервисного проектирования.
- Каждый домен может масштабироваться независимо.
- Разделение на домены позволяет установить разные уровни доступа и политики безопасности для каждого домена.
- Простота добавления новых интеграций.
