# Проблемные места

- MSSQL 2008 - устаревшая DWH, в которой сосредоточена вся бизнес-логика.
- Power Builder - устаревшее решение для взаимодействия с данными, не масштабируется под новые требования бизнеса.
- Не поддержан принцип "Database per Service" - все данные лежат в одной СУБД
- Большое количество данных (сотни терабайт) и сложные трансформации замедляют построение отчётов, что снижает производительность и увеличивает TTM.
- Apache Camel - самописная интеграционная шина.
- Сложно интегрировать новые услуги - фармацевтические компании, производителя медицинского оборудования.
- Построение сложных отчётов занимает большое время из-за большого объёма данных и текущего подхода к их обработке.

# Приоритизация проблемных мест методом MoSCoW

## Must Have
- Реализация портала самообслуживания.
- Ускорение построения отчетов.
- Повышение отказоустойчивости системы.

## Should Have
- Ииграция бизнес-логики из DWH в Data Lakehouse.
- Переход на Apache Kafka.

## Could Have
- Реализовать автоматизацию обновления витрины данных.

## Would Like
- Поддержать аналитику медицинских данных.
